# 11408 大观

面向 11408 考研复习的可安装 Web App。当前完成线性代数模块，内容按 CXY-003 / CXY-004 的讲解主线整理，将行列式、矩阵、向量、方程组和特征理论连成一套可检索的结论网络。

## 当前功能

- 72 张线性代数知识卡与逐章时间轴
- 「成立条件—启动信号—考试步骤—易错边界」知识卡
- 必须掌握 / 高频题型 / 综合拔高筛选
- 全文检索、章节跳转与原视频时间段回链
- 掌握进度与复习清单（保存在本机）
- 响应式布局，适配桌面、平板和手机
- PWA 安装、Service Worker 离线缓存与完整图标集

## 本地预览

项目为零依赖静态站点，在仓库根目录启动任意静态服务器即可：

```bash
python3 -m http.server 4173
```

访问 `http://localhost:4173`。
